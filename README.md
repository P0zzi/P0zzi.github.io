# Little Finn Uploader – website

This is the tiny static website (plain HTML and inline CSS, no JavaScript, no trackers, no external resources) served with GitHub Pages at https://p0zzi.github.io/. It is the homepage, Privacy Policy and Terms of Service of "Little Finn Uploader", a private tool used only by the owner of the "Little Finn" YouTube channel to upload videos to that same channel, and it is the web address used by the app's Google Cloud OAuth consent screen.
